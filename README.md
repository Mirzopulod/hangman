# Виселица

Консольная игра «Виселица» на Python. Игрок должен угадать загаданное слово, вводя по одной русской букве за ход. За каждую неверную букву виселица постепенно дорисовывается.

## Возможности

- Случайный выбор слова из файла `words.txt`.
- Проверка введённых букв.
- Защита от повторного ввода одной и той же буквы.
- Отображение текущего состояния виселицы.
- Сообщения о победе и поражении.
- Обработка отсутствующего или пустого словаря.

## Требования

- Python 3
- Файл `words.txt` со словами на русском языке - по одному слову на строку.

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Убедитесь, что файл `words.txt` находится в папке проекта.
3. Запустите игру командой:

   ```bash
   python main.py
   ```

## Как играть

1. Выберите пункт `1`, чтобы начать новую игру.
2. Вводите по одной русской букве.
3. Не повторяйте уже введённые буквы.
4. Попробуйте угадать слово до того, как виселица будет полностью нарисована.
5. Выберите `0` в меню, чтобы выйти из игры.

## Структура проекта

- `main.py` — код игры.
- `words.txt` — список слов для игры.

## Цель проекта

Учебный проект для практики Python: работа с функциями, циклами, списками, строками, пользовательским вводом и файлами.
